## 🚀 Running Locally

### Option 1: Direct File Open (Zero Setup)
Simply double-click `index.html` in your file explorer. It will open immediately in any modern web browser without needing any server or dependencies!

### Option 2: Lightweight Node.js Server
If you want to run via Node:
```bash
npm start
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.

### Option 3: Python Built-in Server
```bash
python -m http.server 3000
```
Then visit [http://localhost:3000](http://localhost:3000).

## 🌐 Free 1-Click Deployment Options

### 1. GitHub Pages (Recommended)
1. Push this folder to a GitHub repository (e.g. `arsalanfiroz/portfolio` or `arsalanfiroz.github.io`).
2. Go to your repo **Settings &rarr; Pages**.
3. Under **Branch**, select `main` (or `gh-pages`) and `/root`, then click **Save**.
4. Your portfolio will be live at `https://arsalanfiroz.github.io`!

### 2. Vercel
```bash
npx vercel
```
Follow the prompts (accept default settings) &mdash; your site will deploy to a global edge CDN in 15 seconds.

### 3. Netlify
Drag and drop this folder directly into the [Netlify Drop](https://app.netlify.com/drop) dashboard or use the Netlify CLI.
